== Supported BPMN elements

All BPMN elements that go through an idle state are supported.

[%header,cols="3"]
|===
^|Element 
^|Type 
^|Description 

|Intermediate Message | Event | Causes idle time until a message is provided
|Intermediate Signal | Event | Causes idle time until a signal is provided
|Intermediate Timer  | Event | Causes idle time until the timer times out
|User Task node | Activity | Calls User Tasks subsystem and waits until a human completes the task
|User Task Notification | HT Event | Notifies HT
|User Task Deadline  | HT Event | Deadline notifications
|Boundary Event Message   | Event | Causes a branch in a path of an ongoing activity execution when a message reaches it (might cancel or not)
|Boundary Event Signal  | Event | Causes a branch in a path of an ongoing activity execution when a signal reaches it (might cancel or not)
|Boundary Event Timer  | Event | Causes a branch in a path of an ongoing activity execution when a timer times out (might cancel or not)
|Start Event Message  | Event | Starts an execution of a workflow when a message reaches the engine
|Start Event Signal  | Event | Starts an execution of a workflow when a signal reaches the engine
|Event Gateway  | Event | Causes several events to be waited on simultaneously
|Ad-hoc Tasks  | Activity | Allows triggering tasks when there is no incoming connection
|Ad-hoc Subprocess  | Event | Allows triggering a subprocess when there is no incoming connection to a subprocess
|Call Activity | Activity | Calls a reusable sub-process external to the current process definition. The called element can be a static process ID or a runtime expression using the `#{variable_name}` syntax, where the sub-process to invoke is resolved from a process variable at runtime.
|===

For more information about BPMN, see the https://www.omg.org/spec/BPMN/2.0/About-BPMN[Business Process Model and Notation (BPMN) specification].

NOTE: The `#{...}` expression syntax in the Call Activity `calledElement` attribute is not part of the BPMN 2.0 specification. It is a {PRODUCT_SHORT}/Kogito extension that provides runtime process variable interpolation, consistent with the expression interpolation supported elsewhere in {PRODUCT_SHORT} BPMN properties, such as task parameters and URL fields in REST Work Item Handler tasks. For more information, see xref:../08-developing-stateful-workflows/authoring-workflows.adoc#dynamic-call-activity[Authoring Workflows → Calling sub-processes dynamically].
