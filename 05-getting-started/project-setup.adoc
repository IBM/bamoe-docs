= _Business Service_ project setup
include::../_partials/attributes.adoc[]
include::../_styles/images.adoc[]

_Business Services_ are microservice Java applications built on top of Quarkus or Spring Boot, containing {PRODUCT_SHORT} runtime libraries and Business Automation assets such as Workflows (BPMN), Decisions (DMN), Rules (DRL), and spreadsheet Decision Tables (XLS or XLSX), following https://maven.apache.org/guides/introduction/introduction-to-the-standard-directory-layout.html[Maven's standard directory layout]. If you are using Gradle, follow https://docs.gradle.org/9.2.1/userguide/organizing_gradle_projects.html[Gradle's standard directory layout]. 

[#gs-accelerators]
== Introducing Accelerators

Instead of creating a _Business Service_ project from scratch, you can use an Accelerator — a pre-configured project template for Quarkus or Spring Boot with Maven or Gradle — to instantly scaffold the project structure around your existing Decisions and Workflows. Accelerators can be applied directly from {CANVAS} or {DEV_TOOLS}, and organizations can also publish custom Accelerators to standardize project setup across teams.

For the full list of available Accelerators, how to access them, and more information, see xref:../06-available-components/accelerators/intro-accelerators.adoc[Available components → Introducing Accelerators].

[#starting-project-canvas]
== Starting on {CANVAS}

Before you create a new _Business Service_ project on {CANVAS}, make sure you have installed {CANVAS} on your device. 

To install {CANVAS}, follow instructions provided by your organization or install {CANVAS} locally. For more information on local installation, see xref:../03-installing/development-environment.adoc[Installing → Development Environment].

To create a new _Business Service_ project on {CANVAS}, see xref:../06-available-components/accelerators/using-accelerators-canvas.adoc[Available components → Using Accelerators in {CANVAS}].

=== Using {DEV_TOOLS} after starting on {CANVAS}

If you want to continue developing on {DEV_TOOLS} after starting on {CANVAS}, you can do one of the following:

* Create a new Git repository in your Git provider of choice directly in {CANVAS}, then clone it locally.
* Download your newly created _Business Services_ project from {CANVAS} as a .zip file and unpack it on your device.

== (Advanced) Manually creating a Java project

If you have your own preferences when creating new projects, create your Java project manually. You can decide which {PRODUCT_SHORT} dependencies you need based on xref:../12-reference/maven-repository-libraries.adoc[Reference → {MVN_REPO} libraries].

If you are planning on running Decisions, Rules, and/or spreadsheet Decision Tables on embedded Java mode using programmatic {PRODUCT_SHORT} Java API, see xref:../07-developing-decisions-rules-and-test-scenarios/embedded-dmn-drl.adoc[Decisions and Rules _Business Services_ in embedded Java mode].
