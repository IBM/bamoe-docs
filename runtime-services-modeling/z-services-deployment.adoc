= Building and Deploying _Business Services_on IBM z/OS
include::../partials/attributes.adoc[]
include::../styles/images.adoc[]

You can build your _Business Services_ to run on Openshift running on an IBM z/OS cluster supporting s390x. A set of deliverables are included in the {PRODUCT_SHORT} distribution to enable you to install {PRODUCT_SHORT} components and develop your _Business Services_ that will run on the IBM z/OS s390x Linux platform. The host machine architecture is automatically resolved when you pull the {PRODUCT_SHORT} container images. Specific s390x images (named `...-s390x.tar.gz`) are provided for the following packages:

* {CANVAS}
* {EXT_SERVICES}
* {CORS_PROXY}
* {MANAGEMENT_CONSOLE}
* {MVN_REPO}
* {QUARKUS_DEV_UI}
* {SPRING_WEB_CONSOLE} - to be confirmed
* {DATA_CLEANUP}
* {MCP_SERVER}

If you want to pull a specific platform image you can use the `—platform` flag in your `docker pull` command.
