= Building and Deploying _Business Services_on IBM z/OS
include::../partials/attributes.adoc[]
include::../styles/images.adoc[]

You can build your _Business Services_ to run on Openshift running on an IBM z/OS cluster. A set of deliverables are included in the {PRODUCT_SHORT} distribution to enable you to develop for services for the Z platform. 

While pulling images, user can mention the desired platform by passing —platform flag to docker pull. If no —platform is passed, user native architechture is pulled. We can document this as needed.
One extra tar file (-s390x.tar.gz)for each image to be published
