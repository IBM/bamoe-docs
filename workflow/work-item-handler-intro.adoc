= WorkItemHandler Library

The BAMOE WorkItemHandlers Library is a framework providing a centralized collection of BAMOE-supported Work Item Handlers (WIHs). This library is designed to be a logical grouping of handlers, and it includes independent dependencies for each handler.

You can also create a custom WorkItemHandler. For more information, see the xref:./extending-workflow-engine.adoc#custom-wih[Creating a custom WorkItemHandler] section.

REST Service Call Task is a new custom BPMN task following Gen AI and AI Agent Tasks design patterns. For more information about Gen AI and AI Agent Task, see xref:../integrating-ai/custom-generative-ai-task.adoc[Using a Gen AI task in BPMN]. The REST Service Call Task is configured in the BPMN Editor task palette and the configuration is available in the dedicated properties panel. For more information about the BPMN Editor, see xref:../workflow/authoring-workflows.adoc#workflow-bpmn-editor[Authoring Workflows with BPMN].

REST Service Call Task uses standard constructs such as https://www.omg.org/spec/BPMN/2.0/[`ioSpecification`], https://www.omg.org/spec/BPMN/2.0/[`dataInput`], and https://www.omg.org/spec/BPMN/2.0/[`dataOutput`]. The task supports process variable interpolation syntax - `#{expression}`, and provides real-time validation with development-time feedback. It also includes authoring-time testing capabilities and supports HTTP methods (GET, POST, PUT, DELETE, PATCH) with dynamic headers and query parameters. The task is designed to be a single source of truth, with automatic BPMN model serialization and no need for `.wid` files.

== Getting started

BAMOE WorkItemHandlers Library provides a set of pre-built WorkItemHandlers that can be used out of the box. The library provides a set of examples that can be used to learn how to use the library and can be used as a starting point for creating your own custom WorkItemHandlers.

If you do not have an existing project, to get started with the BAMOE WorkItemHandlers Library, do the following steps:

. Create new project using BAMOE Accelerator.
. Open workflow in BPMN Editor.
. Add REST Service Call Task.
. Configure through properties panel.
. Deploy and run.

If you already have a project, with BAMOE WorkItemHandlers Library you can access new authentication and configuration options with comprehensive guidance for REST integration patterns. You can adopt the library in your existing projects without breaking changes, since existing REST WorkItemHandlers are still supported. You can leverage new validation rules for better development-time feedback and update workflows to use new REST Service Call Task for enhanced visual configuration.
