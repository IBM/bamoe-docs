= AI Agent Task WorkItemHandler
include::../partials/attributes.adoc[]
include::../styles/images.adoc[]

The AI Agent Task WorkItemHandler (WIH) enables connection to an AI provider at runtime in Business Service containing stateful Workflows.

The `com.ibm.bamoe:bamoe-ai-agent-task-work-item-handler-quarkus` and `com.ibm.bamoe:bamoe-ai-agent-task-work-item-handler-spring-boot` dependencies enable custom AI agent to be integrated into Workflows, for _Business Services_ built with Quarkus or Spring Boot. For more information about WIH dependencies, see xref:../reference-guide/maven-repository-libraries#ai-integration[AI integration].

For more information about AI Agent Task, see xref:../integrating-ai/ai-agent-task.adoc[Using AI Agent Tasks in Workflows].
