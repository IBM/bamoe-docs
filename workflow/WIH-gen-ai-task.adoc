= GenAI Task WorkItemHandler
include::../partials/attributes.adoc[]
include::../styles/images.adoc[]

The Gen AI Task WorkItemHandler (WIH) configure a System prompt that enables the LLM to perform variable interpolation when you create your prompt in the **Prompt** field, aligned with IBM's prompt injection prevention guidelines.

The `com.ibm.bamoe:bbamoe-gen-ai-task-work-item-handler-quarkus` and `com.ibm.bamoe:bamoe-gen-ai-task-work-item-handler-spring-boot` dependencies enable Gen AI tasks to be integrated into Workflows, for _Business Services_ built with Quarkus or Spring Boot. For more information about WIH dependencies, see xref:../reference-guide/maven-repository-libraries#ai-integration[AI integration].

For more information about Gen AI Task, see xref:../integrating-ai/custom-generative-ai-task.adoc[Using a Gen AI task in BPMN].
