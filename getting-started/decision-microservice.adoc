You can learn about the deployment of an existing Decision Model and Notation (DMN) and the validation of its decisions, described in the following sections:

- Examine an existing DMN file.
- Import the DMN file.

== Prerequisites

Before you start, make sure the following requirements are met:

* xref:../installation/configure-maven.adoc[BAMOE Maven repository installed]
* xref:../installation/canvas.adoc[{CANVAS} installed]

== Examine the existing DMN Diagram

The following example describes an insurance price calculator based on an applicant's age and accident history. You can check the DMN model at {BAMOE_DOCS_EXAMPLES_DOCS_LINK}/dmn/insurance-pricing.dmn[insurance-pricing.dmn].

This example consists of a simple DMN model, which is represented by the following diagram:

image::insurance-price-drd.png[Insurance Pricing Requirements Diagram, 400]

In this decision diagram, the applicant's age and accident history are the required inputs for the decision node *Insurance Total Price*. This node has a following Decision Table:

.DMN Decision Table
image::insurance-price-dt.png[Completed Decision Table,600]

The DMN Decision Table includes a `hit policy`, `inputs` columns, and `outputs` columns. In this example, the `hit policy` is `U`, which means `Unique`, therefore only one input rule should be matched per time. The `inputs` are `Age` and `had previous incidents` and the combination of both creates a rule. The result of this rule is the `outputs` column, which in this case is the "Insurance Total Price".

The conditions for the `Age` input are defined using the Friendly Enough Expression Language (FEEL).

== Import the DMN file into {CANVAS}

To import the GitHub repository directly to {CANVAS}, follow these steps:

. In the ** </> From URL** section of **Import** panel, copy and paste the following link, then click **Import**.

+
[source,console,subs="+attributes"]
----
https://github.com/IBM/bamoe-docs/blob/9.3.x/_code/docs/dmn/insurance-pricing.dmn
----

+
After importing the project, you can see the DMN Editor with the **insurance-pricing** DMN model displayed. If, instead of pointing to a particular DMN, you pointed to an entire project, any DMN/BPMN models associated with it would be able to be viewed/edited within {CANVAS}.

. To get the DMN running within the browser session itself, click **Run**.

+
This will have a section of the browser turn into a form you can modify. You can also change the view to a table by clicking **table** icon in the form.

. Modify the checkbox based on the boolean of `had previous incidents` and set an `Age` based on the data type being a number.

. To add a new input, click **plus** icon in the form.

+ 
If you use table view, to add the next input, click a **plus** icon below the last row of your table.

== Deploy

To use {CANVAS} to deploy your DMN model to a Kubernetes cluster, do the following steps:

. Connect to your Kubernetes cluster.

.. Click **user** icon in the page header to open the **Connected accounts** panel.
.. Click **Connect to an account** to setup a new account.

. Select a provider. For this example, use a local Kubernetes cluster. In production use your own internal Kubernetes. To continue, click **Kubernetes**.

. Add your Kubernetes cluster information.

.. (Optional) If you want to create a local cluster, click *Configure a new local Kubernetes cluster through the guided wizard* and follow the instructions.

. Click **Connect**.

. After you have setup your credentials click **Deploy** and select the DMN model.

+ 
Your new deployment will appear in the **Dev Deployments** dropdown. It will take about 30 seconds to be ready, and a green check will appear. 

. Select on your deployment.

+ 
A new window appears with the equivalent form of your DMN. You can share the deployed URL with everyone who has access to your cluster.
