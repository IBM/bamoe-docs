As mentioned previously, {CANVAS} does not feature its own authentication mechanism.
Instead, {CANVAS} allows the linking of existing accounts from Git and Cloud providers.
These accounts are utilized for Git operations such as Pull and Push, and for creating Dev Deployments, respectively.

All connected accounts are visible in the Accounts dialog, which is accessible through the person icon in the top-right corner.
This dialog displays the number of repositories and deployments being used by those accounts.
Clicking on the arrow provides further information about the accounts, including the date they were linked to {CANVAS}.
 s
Accounts can be removed from {CANVAS} through the Accounts dialog.
Removing an account will result in repositories linked to Git provider accounts losing the ability to Push and Pull.
The account linked to a repository can be changed at any time using the dropdown available on the Editor page of any file in the repository.

== Connecting to Git Providers

BAMOE Canvas supports integration with the following Git providers:

* GitHub Enterprise Server
* GitLab
* Bitbucket Data Center

Procedure

. Navigate to Profile → Connect to an Account in BAMOE Canvas.
. Select your Git provider from the list.
. Provide the required credentials:
        For GitHub Enterprise Server and GitLab: use a Personal Access Token
        For Bitbucket Data Center: use Username and Personal Access Token

Note: You must authenticate using credentials or a personal access token associated with your Git provider. Authentication sessions can be managed through the Accounts dialog in Canvas settings.

Integration Features

BAMOE Canvas supports the following Git integration features:

    Repository Cloning: Clone entire repositories into the BAMOE workspace
    Branch-Specific Cloning: Clone repositories from specific branches
    Import Files: Import specific files from repositories or branches
    Push and Pull Changes: Sync changes between BAMOE workspace and remote repositories
    Create Repository: Create new repositories from within BAMOE Canvas
    Code Snippets: Manage personal and project-level code snippets
