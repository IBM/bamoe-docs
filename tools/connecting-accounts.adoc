= Connecting to AI, Git, and Cloud Providers

include::../styles/images.adoc[]

{CANVAS} does not feature its own authentication mechanism. Instead, {CANVAS} allows the linking of existing accounts from AI, Git, and Cloud providers. These accounts are utilized for Git operations such as Pull and Push, for creating Dev Deployments, and for accessing AI-powered services.

All connected accounts are visible in the Accounts dialog, which is accessible through the person icon in the top-right corner. This dialog displays the number of repositories, deployments, and AI services being used by those accounts. Clicking on the arrow provides further information about the accounts, including the date they were linked to {CANVAS}.

Accounts can be removed from {CANVAS} through the Accounts dialog. Removing an account will result in repositories linked to Git provider accounts losing the ability to Push and Pull. The account linked to a repository can be changed at any time using the dropdown available on the Editor page of any file in the repository.

== Connecting to Git Providers

{CANVAS} supports the integration with GitHub, GitHub Enterprise Server, GitLab, and Bitbucket Data Center. This integration enables users to connect their Git accounts to perform repository operations such as cloning, importing files, pushing and pulling changes, and creating repositories directly from the {PRODUCT_SHORT} workspace.

.Procedure
To connect to a Git provider account in {CANVAS}, 

. Navigate to *Profile* → *Connect to an Account*. 
. From the list of available Git providers, select the provider you wish to integrate. 
. Provide the Personal Access Token to establish the connection.

NOTE: For GitHub, GitHub Enterprise Server and GitLab, use a Personal Access Token. For Bitbucket Data Center, use Username and Personal Access Token. For more information on generating Personal Access Tokens, see xref:https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens[GitHub Docs], xref:https://docs.gitlab.com/user/profile/personal_access_tokens/[GitLab Docs] and xref:https://confluence.atlassian.com/bitbucketserver/http-access-tokens-939515499.html[Bitbucket Support].
