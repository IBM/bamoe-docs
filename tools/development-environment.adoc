= Development Environment

include::../styles/images.adoc[]

This section provides information about the features that support creating and managing Workflows, Decisions, and Rules in your development environment. It includes BAMOE Canvas, a browser-based authoring tool for Decisions and Workflows, and BAMOE Developer Tools for VS Code, which provide visual editors and integrations to streamline development.

** xref:canvas.adoc[{CANVAS}] - provides you with introductory information on {CANVAS}.
*** xref:creating-models.adoc[Creating Models] - describes how to start creating models in the appropriate editors.
*** xref:importing-existing-projects.adoc[Importing existing projects] - describes how to import your existing projects from different sources to edit, test and execute them using {PRODUCT_SHORT} tools.
*** xref:connecting-accounts.adoc[Connecting to Git and Cloud providers] - describes how to configure connections to your existing Git and Cloud accounts to manage and execute your Decisions and Workflows.
*** xref:working-with-git.adoc[Working with Git] - describes how {CANVAS} streamlines the usage of Git to store and managed your Decisions and Workflows.
*** xref:applying-accelerators.adoc[Using Accelerators] - describes the Accelerators (project templates) that are provided by {CANVAS} out of the box facilitating the development and control of your existing Decisions and Workflow.
*** xref:dev-deployments.adoc[Creating Dev Deployments] - describes how to connect to a local or remote Kubernetes instance (or a remote OpenShift instance) to execute your Decisions and Workflows for development purposes only.
*** xref:create-custom-dev-deployment-image.adoc[Creating and customizing BAMOE Canvas Dev Deployments] - describes the extensive customization capabilities to enable you to test in a custom Dev Deployment. 
*** xref:dev-deployment-upload-service.adoc[Dev Deployment Upload Service] - describes how to upload a ZIP file to HTTP server provided by the Dev Deployment Upload Service. 
** xref:developer-tools-for-vscode.adoc[{DEV_TOOLS}] - introduces any specific information on editing and executing your Decisions and Workflows in the Developer Tools for VS Code version.
*** xref:importing-dmn-data-types-from-java-classes.adoc[Importing DMN Data Types from Java classes] - describes how to import DMN data types directly from Java classes
*** xref:form-generation.adoc[Form code generation for User Tasks] - introduces any specific information on editing and executing your Decisions and Workflows in the Developer Tools for VS Code version.
