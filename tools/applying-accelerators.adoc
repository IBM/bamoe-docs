= Using Accelerators 
include::../partials/attributes.adoc[]
include::../styles/images.adoc[]
Accelerators are project templates that can be applied to existing folders containing Workflows (BPMN), Decisions (DMN), and Rules (DRL), transforming them into complete _Business Service_ projects that can be built, tested, executed, and deployed with your preferred development framework.

{CANVAS} provides a set of default Accelerators:

* `Quarkus (DMN)` 
* `Quarkus (Full)`
* `Spring Boot (DMN)` 
* `Spring Boot (Full)`

For other ways to start a _Business Service_ project, see xref:../getting-started/project-setup.adoc[Getting started → Initial _Business Service_ project setup].

== From existing Decision and Workflow models

To use Accelerator in your _Business Service_ project, select the Accelerator from *Apply Accelerator* dropdown. After you selected the Accelerator, you can see the displayed label in the project header.

//.“Accelerator label” shown for a multi-file project
//image::tools/image20.png[“Accelerator label” shown for a multi-file project]

Applying an Accelerator creates a `.kie-sandbox` directory at the project root. This directory will have an `accelerator.yaml` file, which contains all information necessary for the apply operation. The file indicates that an Accelerator was applied to the project and should not be removed. 

Clicking on the Accelerator label will open a dialog that shows the `accelerator.yaml` information.

//.Accelerator dialog shown for a multi-file project
//image::tools/quarkus-full-accelerator.png[“Accelerator dialog for a multi-file project]

[NOTE]
====
Do not modify the contents of the `accelerator.yaml` file as it is used by {CANVAS} to track the applied Accelerators. Modifying the file may mislead users or break the {CANVAS} integration.
====

You can also use custom Accelerators. For more information, see xref:../installation/canvas.adoc#custom-accelerators[Installation → {CANVAS} -> Configuring custom Accelerators for your organization].
