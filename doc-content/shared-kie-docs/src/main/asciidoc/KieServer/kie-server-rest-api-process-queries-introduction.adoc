= Process queries REST API

The {KIE_SERVER} REST API supports the following endpoints for querying process definitions and process instances. The {KIE_SERVER} REST API base URL is `\http://SERVER:PORT/kie-server/services/rest/`. All requests require HTTP Basic authentication or token-based authentication for the `kie-server` user role.



With the process queries REST API, you can perform the following actions:

* Retrieve information about all groups, roles, users, and their granted permissions

* Create, update, or delete groups and users

* Update granted permissions for groups, roles, and users

* Retrieve information about groups and roles assigned to the users
