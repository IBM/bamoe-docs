= Managing custom tasks in VS Code

In VS Code, managing custom tasks for {PRODUCT} involves defining and deploying Work Item Handlers (WIHs) that extend BPMN capabilities to support external operations such as REST calls, database interactions, or SOAP services. These handlers are Java classes that implement the `org.kie.api.runtime.process.WorkItemHandler` interface, using the `executeWorkItem(...)` and `abortWorkItem(...)` methods to control task execution. Handlers are registered through configuration files like `kie-deployment-descriptor.xml` or `kmodule.xml`, while task metadata is described in `.wid` files using MVEL syntax. These `.wid` files should be placed either in the global directory under the project root or alongside the BPMN file. The subsequent sections outlines how to create, configure, and deploy custom tasks using VS Code.

.Prerequisites

Ensure the following tools are installed:

* Java JDK 11 or later
* Apache Maven
* Visual Studio Code with Java and Maven extensions
