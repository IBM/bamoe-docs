= Not supported in 9.3.1
include::../partials/attributes.adoc[]
include::../styles/images.adoc[]

This section lists the features that are not supported in {PRODUCT_SHORT} v9, showing their replacement.

[%header,cols="3"]
|===
^| Feature
^| Status in {PRODUCT_SHORT} v9.
^| Notes

| **Business Central**
| Not available in v9. Replaced by {CANVAS}, {DEV_TOOLS}, and {MAVEN_REPO}.
a| * **{CANVAS}**: Web-based editor for BPMN and DMN.
  * **{DEV_TOOLS}**: IDE extension for BPMN, DMN, and Test Scenarios.
  * **Maven Repository**: For dependency management.

| **KIE Server**
| Replaced by Quarkus/Spring Boot runtimes.
| For more information, see xref:05-02-upgrading-client-server-projects.adoc[Upgrading client-server projects].

| **SmartRouter**
| Not available in v9. Replaced by Kubernetes-native service discovery and orchestration.
| Use any cloud-compatible load balancing solution as an alternative.

| **Asset Authoring Limitations**
| Supports BPMN and DMN only. Other asset types are not supported.
a| * **{CANVAS}**: BPMN/DMN. 
* **{DEV_TOOLS}**: BPMN/DMN/Test Scenarios.

| **Legacy Form Modeler**
| Not supported in v9. All v8 `.frm` files need to be recreated using form code generation for User Tasks.
| For more information, see xref:../tools/form-generation.adoc[Form code generation for User Tasks].

| **Custom Dashboards and Reports**
| Not available in v9. Use Prometheus and Grafana.
| Use Management Console for basic process monitoring as an alternative.

| **Database Support**
a| * **Supported:** SQL Server, PostgreSQL, Oracle. 
* **Not supported:** Sybase, EDB, others.
| For more information, see xref:../release-notes/supported-environments.adoc[supported environments].

| **Case Management**
| Full CMMN is not available in v9. Replaced by Adhoc (Flexible) Processes.
a| * **Supported Features:** Ad-hoc processes and subprocesses, milestones, dynamic tasks and processes, signal-based triggering.
* **Not Supported:** case lifecycle operations (close, reopen, cancel, destroy), case ID generator, case-specific events and listeners, per-case runtime strategy
* For more information, see xref:05-10-upgrading-case-management-project.adoc[Upgrading Case Management projects].

| **Build from UI**
| Not available in {CANVAS}. Projects must be built using Maven.
| Use `mvn clean package` command.

| **Predefined WorkItemHandlers**
a| * **Available**: WorkItemHandlers or REST service calls.
* **Not available:** CamelCXFConnector, CamelFTPConnector, KafkaPublishMessages, WebServiceTask. 
| For more information, see xref:05-05-upgrading-custom-work-item-handlers.adoc[Upgrading custom work item handlers].

| **DRL-based Test Scenarios**
| Editing is not supported in v9 tooling, but still supported via Maven. Use JUnit tests for new test cases. 
| DMN-based Test Scenarios are fully supported.

| **PMML (Predictive Model Markup Language)**
| Not available in v9. Replaced by external ML model integration or DMN.
| 

| **Pluggable Variable Persistence**
| Not supported in v9. You cannot customize variable persistence strategy.
| Use standard JPA persistence with custom entities as an alternative.

| **JavaScript Scripting**
| Not supported in v9. Replaced by Java.
| 

| **Guided Decision Tables (XLS/XLSX)**
| Editor is not available, but execution is supported. Edit in external spreadsheet tool, add `org.drools:drools-decisiontables` dependency.
| 

| **Guided Rules**
| Not supported in v9. Convert to DRL or DMN.
a| **Example:**
[source,java]
----
// Convert guided rule to DRL
rule "Approval Rule"
when
    $order: Order(amount > 1000)
then
    $order.setApprovalRequired(true);
end
----

| **Scorecards**
| Not supported in v9. Convert to DMN decision tables
| 

| **Complex Event Processing (CEP)**
| Not supported in v9. Replaced by Kafka Streams or external CEP engine.
| Use event-driven architecture with Kafka as an alternative.
|===
