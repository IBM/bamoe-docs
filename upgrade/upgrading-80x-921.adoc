include::../styles/images.adoc[]

This document provides a comprehensive guide for migrating from Business Automation Manager Open Edition (BAMOE) {VERSION_80X} to BAMOE {VERSION_92X} and a structured approach to the migration process, covering everything from environment setup and project upgrades to operational and performance considerations. As BAMOE evolves, version {VERSION_92X} introduces a modern, cloud-native architecture based on Kogito runtime, offers improved scalability, flexibility, and integration capabilities. However, this shift also brings significant changes in how processes, tasks, persistence, and user management are handled.
