= Development Environment 
include::../partials/attributes.adoc[]
include::../styles/images.adoc[]


The development environment provides the foundation for designing, building, and testing automation solutions. It includes the Maven repository, which hosts artifacts and dependencies required for project builds. Canvas offers a visual design interface for modeling workflows and decision logic, enabling rapid solution development. Developer tools for Visual Studio Code extend the IDE with capabilities for coding, debugging, and integrating with BAMOE services, ensuring a streamlined development experience.
