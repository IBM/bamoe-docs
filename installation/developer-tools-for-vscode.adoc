= Installing {DEV_TOOLS}

include::../styles/images.adoc[]

You can find the developer tools at the Visual Studio Marketplace, as {DEV_TOOLS_VSCODE_MARKETPLACE_LINK}[*{DEV_TOOLS}*].

The visual editors in {DEV_TOOLS} automatically update files to the latest version, making them incompatible with the {PRODUCT_SHORT} version used in _Business Services_. To control updates, turn off the *Auto Update* option. 

If you are developing in Java, make sure you set up the following elements:

* Your domain Java classes.
* The activator Java class file `Activator.java` (required to activate the functionality).

For more information on using the extensions, see xref:../tools/developer-tools-for-vscode.adoc[Available features → {DEV_TOOLS}].
