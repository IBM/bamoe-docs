= Installing {DEV_TOOLS}

include::../styles/images.adoc[]

It is available at the Visual Studio Marketplace, as {DEV_TOOLS_VSCODE_MARKETPLACE_LINK}[*{DEV_TOOLS}*].

We recommend turning off the "Auto Update" option to let you be in control of when to upgrade. The visual Editors included in {DEV_TOOLS} will auto-update files to their newest version, which may make them incompatible with the BAMOE version you are using in your _Business Services_.

If you are developing in Java, you also need to ensure that you need the following as prerequisites:

* Your domain Java Classes
* The Activator Java class file `Activator.java` (required to activate the functionality)

More information on using the extensions can be found in xref:../tools/developer-tools-for-vscode.adoc[Available features → {DEV_TOOLS}].
