== BPMN and DMN Editors

From the Home page, you can create Decisions or Workflows from scratch, or from a sample provided by {CANVAS}.

.Create section at the Home page of {CANVAS}
image::tools/newProject/canvas-create-project.png['Create section at the Home page of {CANVAS}',600]

After you select one of the options, you are taken automatically to a new project that contains only the file you created. The following example shows a new Decision.

.Untitled Decision created from the “Create” section at the Home page of {CANVAS}
image::tools/newProject/canvas-empty-dmn-editor.png['Untitled Decision created from the “Create” section at the Home page of {CANVAS}']

The editor page contains several elements that are described in this section. Some controls are common to both Decisions and Workflows.

.Editor page on {CANVAS} with highlighted common elements for Decisions and Workflows
image::tools/newProject/canvas-dmn-single-file-workspace-overview.png[Editor page on {CANVAS} with highlighted common elements to Decisions and Workflows]


. *File switcher*
+
Use this control to rename the current file.
Click the arrow to display other files in your project.
Search for files and see their image previews.
View the status of changes made to your files and revert those changes individually.

. *File status indicator*
+
Non-clickable visual indicator that shows the persistence status of your file.

. *Accelerator dropdown*
+
Applies a predefined template to your project, accelerating the creation of a runnable _Business Service_ project.

. *New file menu*
+
Adds new files to your project.
Use this menu to create empty Decisions and Workflows, a new Decision or Workflow sample, import from a URL, or upload from your computer.
Note that when importing from a URL, only individual files can be imported.

. *Kebab menu*
+
Provides additional operations. Use this menu to create a new commit in your project or delete your file.

. *Problems tab*
+
Shows issues with your file, both statically and when running it.
More on running Decisions in the xref:../../../07-developing-decisions-rules-and-test-scenarios/running-decisions.adoc[Running Decisions] section.

You can expand this single-file project by adding more files using the *New file menu*. Additional controls become available when a project contains more than one file.

.Editor page on {CANVAS} with highlighted common elements for Decisions and Workflows, for multi-file projects
image::tools/newProject/canvas-multi-file-workspace-overview.png['Editor page on {CANVAS} with highlighted common elements to Decisions and Workflows, for multi-file projects']

. *Back to Home page button*
+
Navigate back to the Home page.

. *Git authentication select*
+
Select which account to use when performing Git operations.
More on that at xref:working-with-git.adoc[Working with Git].

. *Repository type label*
+
Non-clickable label that shows the type of your repository. Possible values:
+
* *Ephemeral* → This repository is not synced to any remote Git repository and exists only in your browser.
* *Repository* → This repository is linked to a GitHub, Bitbucket, or GitLab repository.
* *Git repository* → This repository is linked to a remote Git repository from an unknown Git provider.

. *Repository name*
+
The name of your repository. Click this element to rename it.
This name is specific to {CANVAS} and does not change the remote repository name.
To change the name of your remote Git repository, go directly to the Git provider website, such as GitHub.

. *Repository status indicator*
+
Shows the status of your repository. Click this element to see all changes made since your last commit and revert them all. To revert changes to individual files, use the *File switcher*. Possible values:
+
* *Green check* → Your local copy of the repository is synced with the latest reference downloaded from your linked remote Git repository. In Git terms, HEAD and origin are the same. Note that this does not mean you have the latest changes from the remote Git repository. To make sure you are synced, perform a Sync operation.
* *_M_ (Modified)* → You have made changes since your last commit.
+
For more information, see xref:working-with-git.adoc[Working with Git].
