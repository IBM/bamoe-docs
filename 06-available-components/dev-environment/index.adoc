This section provides information about the features that support creating and managing Workflows, Decisions, and Rules in your development environment. It includes {CANVAS}, a browser-based authoring tool for Decisions and Workflows, and {DEV_TOOLS}, which provide visual editors and integrations to streamline development.

** xref:bamoe-canvas/index.adoc[{CANVAS}] - provides you with introductory information on {CANVAS}.
*** xref:bamoe-canvas/creating-models.adoc[Creating models] - describes how to start creating models in the appropriate editors.
*** xref:bamoe-canvas/importing-existing-projects.adoc[Importing existing projects] - describes how to import your existing projects from different sources to edit, test and execute them using {PRODUCT_SHORT} tools.
*** xref:bamoe-canvas/connecting-accounts.adoc[Connecting to AI, Git, and Cloud providers] - describes how to configure connections to your existing Git and Cloud accounts to manage and execute your Decisions and Workflows.
*** xref:bamoe-canvas/working-with-git.adoc[Working with Git] - describes how {CANVAS} streamlines the usage of Git to store and managed your Decisions and Workflows.
*** xref:bamoe-canvas/applying-accelerators.adoc[Using Accelerators] - describes the Accelerators (project templates) that are provided by {CANVAS} out of the box facilitating the development and control of your existing Decisions and Workflow.
*** xref:bamoe-canvas/dev-deployments.adoc[{CANVAS} Dev Deployments] - describes how to connect to a local or remote Kubernetes instance (or a remote OpenShift instance) to execute your Decisions and Workflows for development purposes only.
*** xref:bamoe-canvas/create-custom-dev-deployment.adoc[Creating and customizing {CANVAS} Dev Deployments] - describes the extensive customization capabilities to enable you to test in a custom Dev Deployment. 
*** xref:bamoe-canvas/dev-deployment-upload-service.adoc[{CANVAS} Dev Deployment Upload Service] - describes how to upload a ZIP file to HTTP server provided by the Dev Deployment Upload Service. 
** xref:bamoe-developer-tools-for-vscode/index.adoc[{DEV_TOOLS}] - introduces any specific information on editing and executing your Decisions and Workflows in the Developer Tools for VS Code version.
*** xref:bamoe-developer-tools-for-vscode/importing-dmn-data-types-from-java-classes.adoc[Importing DMN Data Types from Java classes] - describes how to import DMN data types directly from Java classes
*** xref:bamoe-developer-tools-for-vscode/form-generation.adoc[Form code generation for User Tasks] - introduces any specific information on editing and executing your Decisions and Workflows in the Developer Tools for VS Code version.
