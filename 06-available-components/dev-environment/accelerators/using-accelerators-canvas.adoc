= Using Accelerators in BAMOE Canvas

You can apply an Accelerator to any project open in {CANVAS} directly from the editor toolbar. {CANVAS} provides a set of default Accelerators that you can apply to your project.

[#canvas-prereqs]
== Prerequisites

* You have {CANVAS} running and accessible in your browser.
* You have a project open in {CANVAS}. If you do not have a project yet, create one or import an existing one. For more information, see xref:../bamoe-canvas/creating-models.adoc[Creating models] and xref:../bamoe-canvas/importing-existing-projects.adoc[Importing existing projects].

[#canvas-apply-accelerator]
== Applying an Accelerator

. Open the project in {CANVAS}. The editor toolbar is displayed at the top of the page.
. In the toolbar, click the *Apply Accelerator* dropdown. The dropdown is available in the editor toolbar for both single-file and multi-file projects.
. A list of available Accelerators is displayed. Select the Accelerator that matches your target runtime framework and build tool:
** Choose a *Workflows* Accelerator if your project contains stateful Workflows (BPMN) together with Decisions, Rules, or spreadsheet Decision Tables.
** Choose a *Decisions* Accelerator if your project contains only Decisions (DMN), Rules (DRL), or spreadsheet Decision Tables.
+
For a description of each Accelerator, see xref:intro-accelerators.adoc#available-accelerators[Introducing Accelerators → Available Accelerators].
. In a dialog for the selected Accelerator, click *Apply*. {CANVAS} moves your files to the destination folders, generates the build and configuration files for the selected framework, and creates a new commit.
+
Applying an Accelerator is permanent and cannot be undone within {CANVAS}. If you do not want to apply the Accelerator, click *Cancel* to close the dialog.
. After the Accelerator is applied, the Accelerator name is displayed as a label in the project header. Click the label to open a dialog that shows the contents of the `.kie-sandbox/accelerator.yaml` file created at the project root.
+
[NOTE]
====
Do not modify the `accelerator.yaml` file. It is used by {CANVAS} to track the applied Accelerator, and modifying it may mislead users or break the {CANVAS} integration.
====

== After applying an Accelerator

After applying an Accelerator, you can continue authoring models in {CANVAS} and test their execution using Dev Deployments. For more information, see xref:../bamoe-canvas/dev-deployments.adoc[Dev Deployments].

Because {CANVAS} is designed for visual modeling and does not include an in-browser code editor, you cannot view or edit project configuration files such as `pom.xml` or `application.properties` directly in {CANVAS}. To review and customize the full project structure and configuration files, you can share the project:

* *Export as ZIP* — download all project files by selecting *Share* → *Download "All files"*.
* *Sync with a Git repository* — push your project to a remote repository by selecting *Share* → *<Git Provider>*. For more information, see xref:../bamoe-canvas/working-with-git.adoc[Working with Git].

You can then open the project in {DEV_TOOLS} for VS Code, where you can modify `pom.xml`, configure `application.properties`, and build, test, and deploy the complete _Business Service_. For more information, see xref:using-accelerators-devtools.adoc[Using Accelerators in {DEV_TOOLS}] and xref:intro-accelerators.adoc#project-output[Introducing Accelerators → Generated project structure].
