= Using Accelerators in BAMOE Developer Tools for VS Code

You can apply an Accelerator to a folder in VS Code using the {DEV_TOOLS} commands. The default Accelerators are included in the {DEV_TOOLS} extension.

[#devtools-prereqs]
== Prerequisites

* You have the {DEV_TOOLS} extension installed in VS Code. For installation instructions, see xref:../../03-installing/development-environment.adoc#dev-tools-install[Installing {DEV_TOOLS}].

[#devtools-apply-accelerator]
== Applying an Accelerator

. Open a new or existing folder in VS Code.
. Create Business Automation assets, such as BPMN or DMN models.
. Open the VS Code command palette:
** On macOS: `CMD + SHIFT + P`
** On Windows and Linux: `CTRL + SHIFT + P`
. Type `BAMOE` to filter the available {DEV_TOOLS} commands.
. Run the *Apply Accelerator* command.
. Select the Accelerator you want to apply that matches your target runtime framework and build tool:
** Choose a *Workflows* Accelerator if your project contains stateful Workflows (BPMN) together with Decisions, Rules, or spreadsheet Decision Tables.
** Choose a *Decisions* Accelerator if your project contains only Decisions (DMN), Rules (DRL), or spreadsheet Decision Tables.
+
For a description of each Accelerator, see xref:intro-accelerators.adoc#available-accelerators[Introducing Accelerators → Available Accelerators].

After you complete the steps, your _Business Service_ project structure is ready in the currently open folder. Any existing Business Automation assets are moved to the locations defined by the Accelerator, and uncommitted changes in your workspace are preserved so that you remain in control of your development flow. For more information, see xref:intro-accelerators.adoc#project-output[Introducing Accelerators → Generated project structure].

Alternatively, you can start a new project by directly cloning the desired Accelerator repository branch from GitHub and opening the cloned folder in VS Code. For more information on accessing the repository and its branches, see xref:intro-accelerators.adoc#accessing-accelerators[Introducing Accelerators → Accessing Accelerators]. For practical migration examples that use this method, see xref:../../04-upgrading/upgrading-80x-current/00-intro-tutorials.adoc#_creating_bamoe_v9_projects_with_accelerators[Using BAMOE migration tutorials → Creating BAMOE v9 Projects with Accelerators].

[#devtools-after-applying]
== After applying an Accelerator

After the Accelerator is applied, your folder contains a complete _Business Service_ project structure. You can review the generated build (`pom.xml` or `build.gradle`) and `application.properties` configuration files, and uncomment the blocks that correspond to the capabilities your _Business Service_ requires.

For a full description of the generated files and optional configurations, see xref:intro-accelerators.adoc#project-output[Introducing Accelerators → Generated project structure].
