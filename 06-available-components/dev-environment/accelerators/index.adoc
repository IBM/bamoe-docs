This section describes the available Accelerators and the different ways you can work with them, from applying a built-in template in {CANVAS} or {DEV_TOOLS} to creating your own custom Accelerator for more advanced use cases.

* xref:intro-accelerators.adoc[Introducing Accelerators] - describes the available built-in Accelerators for Workflows and Decisions and when to use each one.
* xref:using-accelerators-canvas.adoc[Using Accelerators in {CANVAS}] - describes how to apply an Accelerator to a new or existing project directly from the {CANVAS} browser-based interface.
* xref:using-accelerators-devtools.adoc[Using Accelerators in {DEV_TOOLS}] - describes how to apply an Accelerator to a new or existing folder in VS Code with {DEV_TOOLS} installed.
* xref:custom-accelerators.adoc[Creating a custom Accelerator] - describes how to build and configure your own Accelerator based on the default templates, adapting it to your project structure and requirements.
