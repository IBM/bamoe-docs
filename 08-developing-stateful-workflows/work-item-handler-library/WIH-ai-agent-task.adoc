include::../../_partials/attributes.adoc[]
:imagesdir: ../../_images
include::../../_styles/images.adoc[]

The AI Agent Task WorkItemHandler (WIH) enables connection to an AI provider at runtime in Business Service containing stateful Workflows.

The `com.ibm.bamoe:bamoe-ai-agent-task-work-item-handler-quarkus` and `com.ibm.bamoe:bamoe-ai-agent-task-work-item-handler-spring-boot` dependencies enable custom AI agent to be integrated into Workflows, for _Business Services_ built with Quarkus or Spring Boot. For more information about WIH dependencies, see xref:../../12-reference/maven-repository-libraries.adoc#ai-integration[AI integration].

For more information about AI Agent Task, see xref:../../11-integrating-with-ai/ai-agent-task.adoc[Using AI Agent Tasks in Workflows].
