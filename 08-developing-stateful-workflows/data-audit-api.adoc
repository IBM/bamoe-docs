= The Data-Audit API

include::../_partials/attributes.adoc[]
include::../_styles/images.adoc[]


You can retrieve information from the Data-Audit using GraphQL, which abstracts how data is fetched and accommodates different query needs.

The path is `http://localhost:8080/data-audit/q` for sending GraphQL queries.

== Example 1

Execute a registered query, e.g., `GetAllProcessInstancesState`, with a definition of the data fields to return:

[source,console]
----
curl -H "Content-Type: application/json" -H "Accept: application/json" -s -X POST http://localhost:8080/data-audit/q/ -d '
{
    "query": "{GetAllProcessInstancesState {eventId, processInstanceId, eventType, eventDate}}"
}'|jq
----

To retrieve the GraphQL schema definition including a list of all registered queries, run a GET command to the `http://localhost:8080/data-audit/r` endpoint. This endpoint can also be used to register new queries.

== Example 2

Register a new query with a complex data type:

[NOTE]
====
When data isolation is enabled (`kogito.persistence.data-isolation.enabled=true`), built-in platform-managed Data-Audit queries are filtered automatically. For custom user-defined queries, you must add explicit filters on the `(process_id, process_version)` and `(root_process_id, root_process_version)` column pairs to restrict results to the local _Business Service_. Filtering on `root_process_id` and `root_process_version` ensures child instances created by Call Activities are properly scoped to the owning parent _Business Service_.
====

[source,]
----
curl -H "Content-Type: application/json" -H "Accept: application/json" -s -X POST http://localhost:8080/data-audit/r/ -d '
{
    "identifier" : "tests",
    "graphQLDefinition" : "type EventTest { jobId : String, processInstanceId: String} type Query { tests (pagination: Pagination) : [ EventTest ] } ",
    "query" : "SELECT o.job_id, o.process_instance_id FROM job_execution_log o"
}'
----

Once registered, the new query can be executed in the same way as pre-registered queries, using the `http://localhost:8080/data-audit/q` endpoint:

[source,]
----
curl -H "Content-Type: application/json" -H "Accept: application/json" -s -X POST http://localhost:8080/data-audit/q/ -d '
{
    "query": "{tests {jobId, processInstanceId}}"
}'|jq
----
