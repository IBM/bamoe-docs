= AI Agent Task Integration in BPMN Editor

== Introduction
The AI Agent task in the BPMN Editor, powered by Langflow, enables you to integrate AI agents into BPMN workflows. Langflow is an open-source tool that provides a visual interface for building AI applications. It allows you to design AI workflows, reuse them across BPMN processes, and integrate with major AI models such as Ollama, OpenAI, and Anthropic. By using Langflow with the BPMN Editor, you can automate tasks and improve workflow efficiency.

For more details on Langflow, visit https://www.langflow.org.

== Prerequisites
* Access to the BPMN Editor.
* A Langflow account with a valid Service URL and API Key.
* Installed Work Item Handler (WIH) dependency for your runtime environment:
** Spring Boot: `bamoe-ai-agent-task-work-item-handler-spring-boot`
** Quarkus: `bamoe-ai-agent-task-work-item-handler-quarkus`
* Updated `application.properties` file with Langflow details:
----
bamoe.workflow.ai-agent-task.provider.langflow.base-url=<your-langflow-host>
bamoe.workflow.ai-agent-task.provider.langflow.api-key=<api-key>
----

== Procedure

=== 1. Configure Langflow as AI Provider
You can configure Langflow through Canvas or the VS Code extension.

==== Canvas Configuration
. Click the profile icon in the top-right corner of Canvas.
. Select *Connected accounts* from the menu.
. Choose *Langflow* from the list of AI providers.
. Enter a display name for your Langflow account.
. Provide the Service URL and API Key.
. Click *Connect* to establish the connection.

==== VS Code Extension Configuration
. Click the profile menu in the bottom-left corner of VS Code.
. Select *Langflow* as the AI provider.
. Enter the Service URL and API Key.
. Save the configuration.

=== 2. Add AI Agent Task in BPMN Editor
. Drag and drop the AI Agent node onto the BPMN canvas.
. In the property panel, select the connected Langflow account.
. Choose the desired Agent or Flow from the dropdown or enter the Agent ID.
. Review the displayed Agent details, including ID, description, MCP status, and tags.

=== 3. Provide Agent Input
* Use the default variable `aiAgentInput` to pass data from previous nodes.
* Customize input text and include process variables using the format `{{variable-name}}`.
* Enable Advanced Mode for syntax highlighting and autosuggest:
** Type `{{` and press Ctrl + Space (or Cmd + Space on Mac) to view available variables.

=== 4. Configure Input and Output Data Mapping
* By default:
** `aiAgentInput` represents the Agent’s input.
** `aiAgentOutput` represents the Agent’s output.
* Add additional variables as needed for custom mapping.

=== 5. Test the Agent
* Use the Preview Table to provide temporary values for process variables.
* Click *Test Agent* to execute the agent and view real-time responses.
* Refine input parameters based on the output until the desired result is achieved.

== Runtime Execution
* Ensure the correct WIH dependency is added to your project.
* Configure Langflow properties in `application.properties`.
* At runtime, the AI Agent task processes input and returns output to the next node in the workflow.
