= Using AI Agent Tasks in Workflows

include::../styles/images.adoc[]

The AI Agent task (technology preview) in the BPMN Editor, powered by Langflow, allows you to add AI Agents in the BPMN Workflows. Langflow is a open-source tool that enables you to:

* Design AI Workflows visually.
* Use pre-built components to simplify your work.
* Create complex agents or flows.
* Reuse your agents or flows in different BPMN Workflows.

Langflow supports major AI models, including Ollama, OpenAI and Anthropic. For more information about Langflow and its capabilities, see https://www.langflow.org.


== Connecting to an AI provider in {CANVAS}

To connect to an AI provider from {CANVAS} follow these steps:

. Navigate to Profile → Connect to an Account.
+
.Selecting an AI provider
image::workflow/langflow-connect.png[width=360]
+
. From the list of available AI providers, select Langflow.
+
.Connecting to Langflow
image::workflow/authenticate-langflow.png[width=360]
+
. Enter a display name, Service URL and API Key for your Langflow account.
. Click Connect.

== Connecting to an AI provider in {DEV_TOOLS}
To connect to an AI provider from {DEV_TOOLS} follow these steps:

. Navigate to the Profile menu in the bottom left corner.
+
.Selecting an AI provider
image::workflow/langflow-connect-vscode.png[width=360]
+
. From the list of available AI providers, select the Langflow.
. Enter the Service URL and API Key to establish the connection.

== Creating a AI Agent task in your workflow

To create a AI Agent task in your Workflow follow this process:

. Drag and drop the AI Agent node from the palette. 
. Navigate to the property panel of the AI Agent task and select the Langflow account you previously connected.
+
.Selecting the Connected Account
image::workflow/langflow-task-props.png[width=360]
+
. Choose an Agent you wish to use.
+
You can either pick an Agent from the dropdown list linked to your Langflow account or enter the Agent ID directly in the input field. Once selected, the property panel displays basic details about the Agent, including its ID, description, MCP status, and the tag category.
+
.Selecting an Agent
image::workflow/selecting-agent.png[width=360]
+
. Specify the AI Agent task input using the `aiAgentInput` variable.
+
To provide input to the AI Agent, you can utilize the `aiAgentInput` variable, which is attached to the input by default. This variable allows the AI Agent to receive data from previously connected nodes, making the input dynamic. You can customize the input text to match your needs and incorporate process variables using the `{{<variable-name>}}` format.
+
.Input Field
image::workflow/aiAgentInput.png[width=360]
+
The input field also includes an Advanced Mode, accessible by clicking the expand icon next to it. This opens an advanced editor with syntax highlighting for `{{<variable-name>}}` and offers autosuggest for process variables.
To use autosuggest, type inside the double curly brackets (`{{...}}`) and press Ctrl + Space (or Cmd + Space on Mac). A dropdown list of data input mapping variables is displayed, showing the variables defined under Data Mapping Properties. Once you update these variables, the suggestion list automatically refreshes to include new ones.
+
.Edit Input Field
image::workflow/edit-input-field.png[width=360]
+

. You can add additional variables as needed to customize the mapping according to your specific requirements using Data mapping.
+
Input and output data mapping works the same way as other task types. By default, `aiAgentInput` and `aiAgentOutput` represent the input and output data.
+
.Input and Output Data Mapping
image::workflow/langflow-data-mapping.png[width=360]
+
. You can Test data process variables used in the input by providing temporary values in the Preview table.
+
These variables are replaced with your input values, enabling you to verify that they are correctly formatted and are populated with the correct data when the Agent execute.
+
. You can use the Test Agent feature in the property panel to verify the AI Agent functionality .
+
This feature executes the agent and displays its real-time response, allowing you to adjust input parameters based on the output until you achieve the desired result.
+
.Test the Agent
image::workflow/test-the-agent.png[width=360]

== Deploying a Business Service with Workflows containing AI Agents

To enable connection to an AI provider at runtime in Business Service containing stateful Workflows, you must:

* Add the relevant work item handler (WIH) dependency to your project, either for Quarkus or Spring Boot. For more information about WIH dependencies, see xref:../reference-guide/maven-repository-libraries#ai-integration[AI integration].
* configure the following evironment variables in the `application.properties` file with the Langflow data. 

[source, properties]
----
bamoe.workflow.ai-agent-task.provider.langflow.base-url=<your-langflow-host>
bamoe.workflow.ai-agent-task.provider.langflow.api-key=<api-key>
----
