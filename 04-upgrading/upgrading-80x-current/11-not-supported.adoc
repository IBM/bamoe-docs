= Features not supported in BAMOE 9.6

include::../../_partials/attributes.adoc[]
:imagesdir: ../../_images
include::../../_styles/images.adoc[]

This section lists the features that are not supported in {PRODUCT_SHORT} {VERSION_RM}, showing their replacement.

[%header,cols="3"]
|===
^| Feature
^| Status in {PRODUCT_SHORT} v9
^| Notes

| **Business Central**
| Not available in v9. Replaced by {CANVAS}, {DEV_TOOLS}, and {MVN_REPO}.
a| * **{CANVAS}**: Web-based editor for BPMN and DMN.
  * **{DEV_TOOLS}**: IDE extension for BPMN, DMN, and Test Scenarios.
  * **{MVN_REPO}**: For dependency management.

| **KIE Server**
| Replaced by Quarkus/Spring Boot runtimes.
| For more information, see xref:05-00-upgrading-projects/05-02-upgrading-client-server-projects.adoc[Upgrading client-server projects].

| **SmartRouter**
| Not available in v9. Replaced by Kubernetes-native service discovery and orchestration.
| Use any cloud-compatible load balancing solution as an alternative.

| **Asset Authoring Limitations**
| Supports BPMN and DMN only. Other asset types are not supported.
a| * **{CANVAS}**: BPMN/DMN. 
* **{DEV_TOOLS}**: BPMN/DMN/Test Scenarios.

| **Legacy Form Modeler**
| Not supported in v9. All v8 `.frm` files need to be recreated using form code generation for User Tasks.
| For more information, see xref:../../06-available-features/dev-environment/bamoe-developer-tools-for-vscode/form-generation.adoc[Form code generation for User Tasks].

| **Custom Dashboards and Reports**
| Not available in v9. Use Prometheus and Grafana.
| Use the {MANAGEMENT_CONSOLE} for basic process monitoring as an alternative.

| **Database Support (Production)**
a| * **Supported:** Microsoft SQL Server, PostgreSQL, Oracle, IBM Db2
* **Not supported:** Sybase, EDB, others
| For more information, see xref:../../01-release-notes/supported-environments.adoc[Supported environments].

| **Case Management**
| Full CMMN is not available in v9. Replaced by Ad-hoc (Flexible) Processes.
a| * **Supported Features:** Ad-hoc processes and subprocesses, milestones, dynamic tasks and processes, signal-based triggering.
* **Not Supported:** Case lifecycle operations (close, reopen, cancel, destroy), case ID generator, case-specific events and listeners, per-case runtime strategy, milestones with conditional expressions.
* For more information, see xref:05-00-upgrading-projects/05-10-upgrading-case-management-project.adoc[Upgrading Case Management projects].

| **Build from UI**
| Not available in {CANVAS}. Projects must be built using standard build tools (Maven or Gradle) via the CLI or CI/CD pipelines.
| Use standard build commands, such as `mvn clean package` or `gradle clean build`.

| **Predefined WorkItemHandlers**
a| * **Available:** WorkItemHandlers or REST service calls.
* **Not available:** CamelCXFConnector, CamelFTPConnector, KafkaPublishMessages, WebServiceTask.
| For more information, see xref:05-00-upgrading-projects/05-05-upgrading-custom-work-item-handlers.adoc[Upgrading custom work item handlers].

| **DRL-based Test Scenarios**
| Editing is not supported in v9 tooling, but test execution is supported via standard build tools (Maven or Gradle). Use JUnit tests for new test cases.
| DMN-based Test Scenarios are fully supported.

| **PMML (Predictive Model Markup Language)**
| Not available in v9. Replaced by external ML model integration or DMN.
| 

| **Pluggable Variable Persistence**
| Not supported in v9. You cannot customize the variable persistence strategy.
| Use standard JPA persistence with custom entities as an alternative.

| **JavaScript Scripting**
| Not supported in v9. Replaced by Java.
|

| **Guided Decision Tables (XLS/XLSX)**
| Editor is not available, but execution is supported. Edit in external spreadsheet tool, add the `org.drools:drools-decisiontables` dependency.
|

| **Guided Rules**
| Not supported in v9. Convert to DRL or DMN.
a| **Example:**
[source,java]
----
// Convert guided rule to DRL
rule "Approval Rule"
when
    $order: Order(amount > 1000)
then
    $order.setApprovalRequired(true);
end
----

| **Scorecards**
| Not supported in v9. Convert to DMN decision tables.
|

| **Complex Event Processing (CEP)**
| Not supported in v9. Replaced by Kafka Streams or external CEP engine.
| Use event-driven architecture with Kafka as an alternative.

| **Process ID restrictions**
| Hyphens break code generation and dots cause schema failures. Use camelCase for process IDs.
|

| **javax → jakarta package migration**
| The v8 service APIs (`org.jbpm.services.api.*`) are not available in v9. Use the auto-generated REST endpoints for all process interactions.
|

| **Variable `context` does not exist**
| The `context` variable is not available in v9. Replace it with `kcontext`.
| The `kcontext` variable is also valid in v8 and ensures cross-version compatibility.

| **Raw `List` type error**
| Raw `List` types trigger Jandex errors. Always specify a type parameter: `List<Type>`.
|

| **Boolean getter method naming**
| Boolean getters should use the `is` prefix instead of `get`.
| While `getApproved()` is syntactically correct and will compile, `isApproved()` is the preferred way according to JavaBeans naming conventions.

| **Hibernate rejects models with `@Entity`**
| Using JPA entities as process variables may result in Hibernate errors. Prefer DTOs, or ensure JPA entities are fully and correctly configured.
|

| **NPE in error handling**
| Accessing error details in catch blocks may cause null pointer issues.
| Always perform null checks and apply null-safe patterns when handling error context variables.

| **DRL rules with rule units**
| DRL rules cannot be combined with rule units.
|

| **`null$` values printed during execution**
| Uninitialized variables may appear as `null$`. Initialize variables with default values instead of leaving them null.
|

| **Null on omitted values**
| When optional variables are omitted, they may be stored as explicit `null` in the database. Assign default values to all optional fields.
|

| **Task name with space**
| Not supported in v9. In BPMN models, avoid spaces in task names.
|

| **Dynamic Call Activity (`#{variable_name}` in `calledElement`)**
| Supported from {PRODUCT_SHORT} 9.6.0 onwards. Previously, using `#{variable_name}` in a Call Activity `calledElement` caused a build error: _illegal '#' character_.
a| {PRODUCT_SHORT} v8 BPMN files using `#{variable_name}` in Call Activities can be deployed to {PRODUCT_SHORT} 9.6.0+ without modification. For more information, see xref:../../../08-developing-stateful-workflows/authoring-workflows.adoc#dynamic-call-activity[Authoring Workflows → Calling sub-processes dynamically] and xref:05-00-upgrading-projects/05-04-upgrading-individual-assets.adoc#dynamic-call-activity-migration[Upgrading individual assets → Dynamic Call Activity].
|===
