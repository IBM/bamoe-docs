IBM® License Metric Tool generates reports to help you maintain compliance with your Virtual Processor Core (VPC) subcapacity license terms. License Metric Tool can calculate VPC consumption only when software identification tags exist and are activated by the customer. 

See the section, https://www.ibm.com/support/pages/downloading-ibm-license-metric-tool-92[License Metric Tool with disconnected scanners to install on Linux or Windows] on the page, for guidelines on how to obtain and install ILMT.

Download the assigned software tags for the corresponding v8.0.x (for example, 8.0.7) download files from the {PRODUCT} 8.0.x software.

To detect PAMOE or DMOE, you must manually deploy software tags according to the ILMT configuration. License Metric Tool generates and assigns dedicated software tags during the creation of the Readiness Package for the latest release of {PRODUCT}.

License Metric Tool automatically detects the following {PRODUCT} 8.0.x (for example, 8.0.7) release chargeable components that are part of the product. The following {PRODUCT} chargeable components require manual deployment of software tags:

To detect PAMOE or DMOE, you must manually deploy software tags according to the ILMT configuration. Complete the following procedure to manually deploy dedicated software tags on each managed node:

.Prerequisites
* ILMT Disconnected Scanner tool installed on your system
* SWID tag files for {PRODUCT} 8.0.x obtained from the product release package or Jira ticket

.Procedure
. Identify the target system where you want to deploy the SWID tags.
+
This should be a system where {PRODUCT} components (PAMOE or DMOE) are installed and need to be tracked by ILMT.

. Obtain the appropriate SWID tag files:
+
* `ibm.com_IBM_Process_Automation_Manager_Open_Edition-8.0.x.swidtag` for PAMOE
* `ibm.com_IBM_Decision_Manager_Open_Edition-8.0.x.swidtag` for DMOE
+
[NOTE]
====
SWID tag files are typically provided with the product release package or attached to the release Jira ticket. Ensure the version number in the filename matches your installed {PRODUCT} version.
====

. Place the SWID tag file in an appropriate directory on the managed node.
+
The SWID tag file can be placed in any directory on the system. Common locations include:
+
* `/opt/ibm/` (Linux)
* A custom directory of your choice
+
Example:
+
[source,bash]
----
sudo cp ibm.com_IBM_Process_Automation_Manager_Open_Edition-8.0.8.swidtag /opt/ibm/
----

. Run the ILMT Disconnected Scanner to detect the deployed SWID tags:
+
[source,bash]
----
cd /path/to/ilmt-scanner
sudo ./run_sw_and_pack.sh
----
+
The scanner generates an output package in the `./output/` directory.

. Verify the scan output:
+
[source,bash]
----
ls ./output/ -ltr
----

. Upload the scan results to the ILMT portal:
+
.. Navigate to the ILMT portal in your web browser.
.. Go to *Management* → *Scan Results Upload*.
.. Upload the package file generated in the `output` folder.

. Import the scan data:
+
.. In the ILMT portal, navigate to *Management* → *Data Imports*.
.. Click *Import Now* to manually trigger the import, or wait for the automatic import (runs every 2 hours by default).

. Verify the SWID tag detection:
+
.. In the ILMT portal, navigate to *Reports* → *Infrastructure* → *Computers*.
.. Locate your system in the list (identified by hostname or IP address).
.. Click on the system entry and select *Software Installations* from the dropdown menu.
.. Verify that the Component Version values for DMOE and/or PAMOE match your deployed {PRODUCT} version.

.Result
The SWID tags are now deployed and detected by ILMT. License Metric Tool will include these components in VPC consumption calculations and compliance reports.

[IMPORTANT]
====
* Repeat this procedure for each managed node where {PRODUCT} components are installed.
* After deploying SWID tags, verify that License Metric Tool reporting matches your currently managed nodes before signing each License Metric Tool report.
* Maintain an inventory of systems with deployed SWID tags for audit purposes.
====
