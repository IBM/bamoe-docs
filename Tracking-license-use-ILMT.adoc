= Tracking license use in ILMT
:DM:
:PAM:
:imagesdir: _images
include::_artifacts/document-attributes.adoc[]


IBM® License Metric Tool generates reports to help you maintain compliance with your Virtual Processor Core (VPC) subcapacity license terms. License Metric Tool can calculate VPC consumption only when software identification tags exist and are activated by the customer. 

License Metric Tool automatically detects the following {PRODUCT_SHORT} 8.0.x release chargeable components that are part of the product. The following {PRODUCT_SHORT} chargeable components require manual deployment of software tags:

[cols="1,1"]
|===
| Chargeable Software Components | Assigned Software tags

| Process Automation Manager Open Edition 
| `ibm.com_IBM_Process_Automation_Manager_Open_Edition-8.0.x.swidtag`

| Decision Manager Open Edition 
| `ibm.com_IBM_Decision_Manager_Open_Edition-8.0.x.swidtag`
|===

*Prerequisites*

* IBM License Metric Tool is installed. For installation options and guidelines, see https://www.ibm.com/support/pages/downloading-ibm-license-metric-tool-92[Downloading IBM License Metric Tool 9.2].

*Procedure*

. Download the software tags for the offering you are installing (DMOE or PAMOE) from the {PRODUCT_SHORT} 8.0.x software downloads.
+
The assigned software tags correspond to your v8.0.x version (for example, 8.0.9).

. Place the downloaded software tag file in a directory of your choice on each managed node where {PRODUCT_SHORT} components are installed.

. Run the ILMT Disconnected Scanner on the managed nodes. For more information about ILMT, see xref:https://www.ibm.com/docs/en/license-metric-tool/9.2.0[IBM License Metric Tool].

. Upload the scan results to your License Metric Tool Server.

. To verify that license reporting is functioning correctly:
.. In License Metric Tool, navigate to *Reports* > *Infrastructure* > *Computers*.
.. Under the IP address(es) of the server running BAMOE components or services, select the appropriate server IP address.
.. Access the *Software Installations* table to see component version values for either DMOE or PAMOE, as identified in the SWID tag.

[NOTE]
====
It is recommended that you verify whether License Metric Tool reporting matches with currently managed nodes before signing each License Metric Tool report.
====
