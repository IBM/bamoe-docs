# IBM BAMOE Documentation

This repository holds the AsciiDoc documentation for IBM Business Automation Manager Open Editions (BAMOE).

## How this repository works

- Each BAMOE version has its own branch, named after the version (for example, `9.6.0`).
- The default branch is the branch of the latest released version.
- The `main` branch contains no documentation. It only holds this README and the license.

To read or contribute to the documentation of a specific version, check out the corresponding branch.
Build and authoring instructions are in the `README` and `CONTRIBUTING.adoc` of that branch.
