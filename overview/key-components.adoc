|Component |Description

|{CANVAS}
|A standalone web application that provides authoring and testing tools for Decisions and Processes in your browser. Business Analysts will find this particularly helpful. Developers may prefer to use the BAMOE Developer Tools for VS Code which provides the same features in addition to enterprise developer features.


|{DEV_TOOLS}
|An integration with Microsoft VS Code editor providees the tools to create, edit, test, and visualize business processes (BPMN), decisions (DMN) and test scenarios (SceSim). These tools, combined with existing Java extensions, provide a fully integrated and consistent workspace for Business Service developers.


|{PRODUCT_SHORT} Accelerators
|A feature used to rapidly create a functioning project starting with a business process or a decision file and adding the necessary files and locations to build and deploy a Business Service. Each new project will contain instructions in a README file, an Apache Maven `pom.xml` file referencing project dependencies, and build the expected file structure for the Business Service.


|{MVN_REPO}
|An image or a zip file which contains all the third-party libraries referenced by core BAMOE components. It can be installed in an artifact repository or locally. It ensures that component versions and references are maintained with supported versions.


|{MANAGEMENT_CONSOLE}
|A Web application that provides a view into a running process. You can view which step a process is in while it is running, trigger new processes, and interact with user/human tasks via forms. 


|{QUARKUS_DEV_UI}
|Tools and views into a Business Service, that can be used during development, to interact and view _Business Services_. These tools run locally and are accessible in your browser. The {QUARKUS_DEV_UI} is built upon the existing Quarkus DevUI.

|{SPRING_WEB_CONSOLE}
|Tools and views into a _Business Service_, that can be used during development, to interact and view _Business Services_. These tools run locally and are accessible in your browser. The {SPRING_WEB_CONSOLE} is 

|{PRODUCT_SHORT} Data Cleanup Tool 
|A tool written in Java to remove out-of-date information from the production database. The Data cleanup tool communicates with all supported databases to remove completed and aborted process instances and related data from a database, ensuring queries continue at acceptable levels of performance.

|{PRODUCT_SHORT} Database mapping libraries for Oracle and MS SQL Server
|Different databases use different reserved words. These mapping libraries adapt the base SQL queries and connections to their respective databases avoiding conflicts with reserved words.

|AI Integrations: {PRODUCT_SHORT} Gen AI task
|A new BPMN workflow task which enables easy invocation of an LLM. The Gen AI task provides input for the provider, model, temperature, token limit and prompt. When executed, the task will use the configured information to query the LLM and return the provided response.

|AI Integrations: {PRODUCT_SHORT} MCP Server (technology preview)
|A Quarkus-based service that exposes BAMOE decision and rule models to external AI agents via the MCP protocol. Allows DMN, DRL, and BPMN decisions and workflows to be exposed as “Tools” to support an Agentic AI landscape. Builds on the Quarkus MCP server extension, more information available at https://docs.quarkiverse.io/quarkus-mcp-server/dev/

|AI Integrations: {PRODUCT_SHORT} AI Agent task
|A new BPMN workflow task which enables an integration with Langflow to select flows or agents to be integrated into BAMOE Workflows.

|Process Instance Migration Tool
|The Process Instance Migration (PIM) integrates with {MANAGEMENT_CONSOLE} and enables you to plan and manage the migration of Process Instances to new Process Definitions, providing full visualization of process definitions, facilitating tasks such as node mapping and migration scheduling. 

|{PRODUCT_SHORT} on OpenShift running on Linux s390x on IBM z/OS
|Container versions of {PRODUCT_SHORT} components that run on OpenShift running on IBM z/OS to enable you to build and deploy _Business Services on and IBM z/OS platform running Linux s390x. 

|{PRODUCT_SHORT} Documentation
|The user documentation source prior to release. At GA documentation source is released to the open source repository and to the IBM Docs platform: https://www.ibm.com/docs/en/ibamoe

|{PRODUCT_SHORT} Examples
| Curated example _Business Service_ projects that showcase the technical and business-oriented capabilities of the product. 

|{PRODUCT_SHORT} OpenAPI and GraphQL specification files
|Comprehensive specifications for all REST API endpoints and GraphQL schema for _Business Services_.
